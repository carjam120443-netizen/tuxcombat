# Characters & Asset Licensing

This file tracks the intended source and licensing status of character and asset material.

## Tux

Tux is the main prototype fighter.

- Character: Tux the Penguin
- Artwork creator: Larry Ewing
- This repository currently draws a simplified procedural penguin rather than redistributing an external Tux image file.
- Do not assume that a downloaded Tux image is automatically free for every use.
- Check the source's current license/permission and applicable trademark guidance before adding external artwork or using the game commercially.

The Linux Foundation states that Tux was created by Larry Ewing and is not owned by The Linux Foundation.

## Future fighters

New fighters should be one of:

1. Original characters made specifically for Tux Combat.
2. Assets with a license that clearly permits redistribution and modification.
3. Assets for which the project has explicit permission.

Record the following for every external asset:

- Asset name
- Creator
- Source
- License
- Required attribution
- Modification permission
- Redistribution/commercial-use terms
- Date checked

## No accidental clones

Characters inspired by open-source culture should still be original designs unless the project has permission to use a specific existing character or mascot.

Do not copy sprites, animations, names, music, stages, logos, or other protected material from commercial fighting games.
