# Contributing to Tux Combat

Thanks for checking out Tux Combat! 🐧

## Development

1. Fork or clone the repository.
2. Open the project in Godot 4.x.
3. Make a focused change.
4. Test the game locally.
5. Commit with a short, useful message.
6. Open a pull request.

## Code style

- Use GDScript.
- Prefer small, readable functions.
- Keep gameplay constants near the top of the script.
- Comment unusual game logic.
- Avoid adding dependencies when a simple Godot solution works.
- Keep the prototype playable after each change.

## Assets

Before committing an external asset, verify its license and record the details in CHARACTERS.md or an appropriate asset credits file.

Original art is preferred.

## Scope

Tux Combat is intentionally starting small. A polished tiny feature is more useful than a huge unfinished system.
